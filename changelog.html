Release history

VidaClip changelog.

Browse 24 version entries from v1.2.10 to v1.2.33. This history includes local builds, with extension-only builds labeled separately.

v1.2.33–v1.2.28

v1.2.33Auto Clip and editable highlightsDesktop
  • Added Auto Clip to the Desktop Workspace for individual YouTube, Facebook, Instagram, and TikTok links.
  • Choose 5, 10, 15, or 20 seconds. Free supports 1–2 drafts per run. Creator, Pro, and Studio support up to 10 and custom lengths.
  • Optionally cut long pauses, generate captions, add a spoken intro, or add sound effects. Each draft opens on its own Studio timeline.
  • Added progress and cancellation, a browser-to-Desktop handoff, and audio ducking under spoken intros.
Official v1.2.33 release
v1.2.32Move clips across tracks and edit overlays on canvasDesktop
  • Drag video between the main track and upper tracks, or drag upward to create a new track.
  • Restored the source-audio lane with a waveform and volume controls.
  • Added a scale slider, separate X/Y scale, rotation, and direct move and resize handles for text and stickers.
  • Added a Speech tab and a title menu action to use selected text as a voiceover.
v1.2.31A cleaner start to new projectsDesktop
  • Replaced the system naming prompt with a VidaClip project dialog.
  • New projects open with a clean Media Bin. Saved downloads are available through Browse saved clips.
  • Choose whether a saved clip goes into the Media Bin or directly on the timeline.
v1.2.30Local captions and Voice StudioDesktop
  • Added caption model and language choices, line-length controls, and caption timing, styling, and cue editing.
  • Import and export SRT or build timed cues from a script.
  • Added Windows and local English neural voices, narration preview, voice profiles from recordings, and placement on selected tracks.
v1.2.29Proxy previews, clip preparation, and automationDesktop
  • Added smaller proxy previews for editing while keeping original media available for export.
  • Added local speed ramps, freeze, reverse, stabilization, enhancement, denoising, and basic text-to-speech.
  • Added the Automation setup and Copy MCP config. Project saves are coordinated with automation edits.
v1.2.28Flexible tracks, project timelines, and local captioningDesktop
  • Added general-purpose tracks that can hold video, captions, and audio, with visibility and mute controls.
  • Create, duplicate, rename, and remove timelines in one project.
  • Added local auto-caption generation and editable caption blocks.
  • Added scrollable Inspector and export panels, animated render progress, and output controls for resolution, frame rate, H.264, HEVC, AV1, and encoders.

v1.2.27–v1.2.22

v1.2.27Studio Editor naming and project home polishDesktop
  • Renamed the main Projects destination to Studio Editor.
  • Made the red Create project action easier to spot on the project home.
v1.2.26Saved projects and automatically detected clipsDesktop
  • Added a project home with Create project, Saved projects, Resume previous draft, and Clips.
  • Pick up finished downloads automatically from your VidaClip Clips folder.
  • Save project drafts separately and reopen them with their media and timeline settings. Project cards include cover previews.
v1.2.25On-clip keyframes, thumbnails, and clip menusDesktop
  • Added timeline keyframe diamonds that can be selected and retimed on the clip.
  • Added playhead-based position and scale controls to the Inspector.
  • Added video thumbnails to the Media Bin and right-click clip controls for editing and transforms.
v1.2.24Animated transforms, speed, transitions, and titlesDesktop
  • Added position and scale keyframes with Linear, Ease, and Hold motion.
  • Added per-clip speed from 0.25× to 4×, with matching audio speed in the export.
  • Added transition timing and preview controls, plus editable title layers with timing, position, color, and size.
v1.2.23Move split clips and leave intentional gapsDesktop
  • Added direct placement of clips on the Studio timeline after splitting.
  • Extended the timeline ruler and canvas beyond the end of the sequence.
  • Added gap-aware preview and export so empty spaces stay in the edit.
v1.2.22More accurate download and render progressDesktop
  • Reworked the Workspace progress monitor with measured progress and elapsed time.
  • Added separate download, audio, rendering, and finalization stages. The bar reserves 100% for a completed save.
  • Added progress reporting for direct links, clip downloads, Studio exports, and metadata cleanup.

v1.2.21–v1.2.15

v1.2.21Detailed AI Label Cleaner activityDesktop
  • Added a before-and-after check for supported metadata markers.
  • The Activity Stream now shows what was scanned, which markers were detected or removed, and where the cleaned copy was saved.
  • Added clearer per-file results for batch cleaning and a message when no matching markers are found.
v1.2.20Filmstrip performance and trim limitsDesktop
  • Moved filmstrip rendering to a lower-priority background process.
  • Kept trim points within the source media duration.
  • Improved adding saved clips to the timeline and restoring drafts.
v1.2.19Faster scrubbing and lighter previewsDesktop
  • Added half-resolution previews while keeping exports based on original media.
  • Added source filmstrip thumbnails and queued seek updates for timeline scrubbing.
  • Improved redraws after seeking so the preview catches up with the playhead.
v1.2.18Better drag-and-drop and an empty timelineDesktop
  • Added a clear empty timeline with Browse and Resume draft actions.
  • Let videos and photos start the main timeline, with audio and overlays placed on their own lanes.
  • Added Alt + mouse wheel and keyboard timeline zoom, and sharper Windows app icons.
v1.2.17Quick Clip and Studio Editor workspacesDesktop
  • Separated the guided Quick Clip layouts from a manual Studio Editor workspace.
  • Added position, scale, and reset controls for clip transforms.
  • Made media cards show the destination lane and support adding assets directly.
v1.2.16Cleaner project startup and timeline readoutsDesktop
  • Start on Import & Media when no footage is loaded and enable export review after media is ready.
  • Refined duration and source counts, trim visibility, and restored-project status.
  • Show clearer empty-state guidance before placing sound or images on a timeline.
v1.2.15Desktop Workspace and embedded Studio overhaulDesktop
  • Added Direct Downloader for individual links, quality selection, and a local AI Label Cleaner for photos and video batches.
  • Opened Studio inside VidaClip Desktop using WebView2. Added blank sessions and local video, audio, and photo import.
  • Rebuilt Studio around a layered timeline with a Media Bin, waveform lanes, dual monitors, camera keyframes, captions and graphics controls, and export review.
  • Improved social link handling and added checks that rendered video and expected audio are readable.

  • Added Video Downloader and AI Label Cleaner tabs, a quality picker, and drag-and-drop file cleaning through Desktop.
  • Added an Open Studio shortcut and cleanup quota status.

v1.2.12Creator Packs and profile previewsExtension build
  • Added Podcast, Gaming, Reaction, and Story starting points with editable camera cuts.
  • Added Quick Director and a locally saved Creator Profile for the social preview.
v1.2.11Plan synchronization and license clarityDesktop + extension
  • Made the extension use the Desktop plan and allowances when connected.
  • Improved active membership, expiry, and Free fallback states.
  • Clarified how to import a video or choose a saved clip to enter Studio.
v1.2.10Studio scrolling and annual license testingDesktop + extension
  • Let the Studio page scroll vertically so controls stay reachable in smaller windows.
  • Added a dedicated local testing mode for one-year plan activation.
